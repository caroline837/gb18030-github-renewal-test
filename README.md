## GitHub encoding check

This README is UTF-8. [gb18030.txt](gb18030.txt) contains the same sample
encoded as GB18030, including supplementary-plane and private-use characters.

Open the text file in GitHub's file viewer and compare it with the sample above.
Correct rendering of this README alone does not demonstrate GB18030 decoding.
A download prompt or garbled text in the file viewer indicates that the sample
is not being displayed correctly; missing glyphs may also depend on your font.

To decode the downloaded file locally:

```sh
iconv -f GB18030 -t UTF-8 gb18030.txt
```
